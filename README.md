# Mohd Nazim Rasalat Portfolio

React portfolio for Mohd Nazim Rasalat, positioned as an SDET / QA Automation Engineer.

## Tech Stack

- React
- React Router
- React Bootstrap
- Bootstrap
- React Icons
- React PDF
- React GitHub Calendar
- React Parallax Tilt
- Typewriter Effect
- React tsparticles

## Available Scripts

### `npm install`

Installs project dependencies.

### `npm start`

Runs the portfolio locally in development mode.

### `npm run build`

Builds the production-ready static app.
